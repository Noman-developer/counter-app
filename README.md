# Counter App

A simple counter app made with JavaScript. You can increase, decrease and reset the number.

## Features

- Increase the count with the + button
- Decrease the count with the - button
- Reset the count back to 0 with the Reset button
- The count can go below zero

## Tech stack

- HTML
- CSS
- JavaScript (no libraries, no build step)

## How to run

1. Open the `app.html` file in your browser (double click it or right click and choose Open With).
2. That is it. There is nothing to install.
